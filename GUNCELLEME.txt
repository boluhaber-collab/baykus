================================================================================
  BAYKUŞ - GÜVENLİ GÜNCELLEME KURALLARI
================================================================================

Bu dosya: kod nasıl güncellenir, veritabanı (baykus.db) nasıl KORUNUR.
Taşınabilir paket ve sade kurulum paketi AYNI kuralı kullanır.

--------------------------------------------------------------------------------
1) İKİ PC = İKİ ROL (karıştırmayın)
--------------------------------------------------------------------------------
  • GÜNCELLEME PC (ev / masaüstü):
      - Kod yazar, test eder, git push yapar.
      - Buradaki baykus.db = deneme; işyeri defteri DEĞİLDİR.

  • İŞYERİ PC:
      - Gerçek defter: apps\api\baykus.db  (en değerli dosya)
      - apps\api\uploads = tasarımlar / belgeler

  KURAL: İşyeri baykus.db ASLA güncelleme PC'deki db ile değiştirilmez.
         USB'den "hepsini üzerine yaz" YASAK.

--------------------------------------------------------------------------------
2) İŞYERİNDE KOD GÜNCELLEME (tek tık)
--------------------------------------------------------------------------------
  Güncelleme bilgisayarında panelden «Yeni Sürüm Oluştur».
  Masaüstüne Baykus_Guncelleme.zip iner.
  Zip'te kod ve (varsa) taşınabilir runtime vardır.
  baykus.db ve uploads ZIP'E GİRMEZ.

  Zip'i USB köküne veya işyeri masaüstüne koyun.
  Adı aynen: Baykus_Guncelleme.zip
  İşyerinde Baykus.bat → «Güncelle». Elle dosya kopyalamayın.

  Güncelle sırası:
    1) Servisler durur. Yedek → Yedekler\once_guncelle_YYYYMMDD_HHMM\
    2) Zip aranır: kurulum klasörü, Masaüstü, USB.
       Yoksa dosya penceresi açılır. Birden fazla zip varsa en yenisi.
    3) Kod ve runtime kopyalanır. baykus.db, uploads, .env KOPYALANMAZ.
       Pakette taşınabilir runtime yoksa işyerindeki runtime SİLİNMEZ.
    4) Yedekteki baykus.db + uploads GERİ YAZILIR.
    5) Servisler yeniden başlar.

  Zip yoksa ve klasör git ise: git pull --ff-only (kirliyse DURUR).
  Elle tüm klasörü silip yapıştırmayın.

--------------------------------------------------------------------------------
3) USB İLE KOD GÜNCELLEME (elle, script yoksa)
--------------------------------------------------------------------------------
  Normal yol bölüm 2'dir (Baykus_Guncelleme.zip + Güncelle). Aşağısı yedek plandır.
  DAHİL ET (üzerine yazılabilir):
    - apps\api\app\  (Python kod)
    - apps\web\src\  (web kod; node_modules hariç)
    - scripts\, docs\, *.md, *.bat, GUNCELLEME.txt, KURULUM.txt

  ASLA ÜZERİNE YAZMA / SİLME (elle kopyada):
    - apps\api\baykus.db
    - apps\api\baykus.db-journal
    - apps\api\uploads\
    - apps\api\.venv\
    - .env / apps\web\.env.local
    - Yedekler\
  Panel «Güncelle» runtime ve node_modules'u pakette varsa yeniler.
  Pakette taşınabilir runtime yoksa işyerindeki runtime silinmez.

--------------------------------------------------------------------------------
4) YAPMAYIN
--------------------------------------------------------------------------------
  ✗ Güncelleme PC'deki baykus.db'yi işyerine kopyalamak
  ✗ Tüm "baykus" klasörünü silip USB'den yeniden yapıştırmak
  ✗ Zip'i açıp "tüm dosyaları değiştir" demek (db de değişir)
  ✗ git reset --hard / git clean -fd (yedeksiz; uploads gidebilir)

--------------------------------------------------------------------------------
5) YEDEK NEREYE?
--------------------------------------------------------------------------------
  guncelle.bat : ...\Yedekler\once_guncelle_YYYYMMDD_HHMM\
  yedek-al.bat : ...\Yedekler\baykus_yedek_YYYYMMDD_HHMM.zip

  Büyük güncellemeden / Excel import'tan ÖNCE yedek alın.

--------------------------------------------------------------------------------
6) KISA ÖZET
--------------------------------------------------------------------------------
  Güncelleme PC = kod    |    İşyeri PC = defter (baykus.db)
  Ev: panel «Yeni Sürüm Oluştur» → Masaüstü\Baykus_Guncelleme.zip
  İşyeri: panel «Güncelle» (zip masaüstünde, USB'de veya klasörde)
  Asla: işyeri db'sini güncelleme db'siyle değiştirmek
